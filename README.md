# AWS Student Community Day Peshawar 2026

A modern, high-performance landing page and content management system for the AWS Student Community Day in Peshawar. Built to deliver a premium attendee experience with lightning-fast load times and seamless interactions.

## Features

- **Neo-Brutalist Design:** Bold typography, stark borders, and high-contrast color palettes.
- **Responsive Layout:** Flawless rendering across mobile, tablet, and desktop devices.
- **Smooth Scrolling:** Custom Lenis scroll integration for a fluid browsing experience.
- **Dynamic Content Showcase:** Dedicated sections for partners, speakers, and organizers with stagger animations.
- **Admin Panel:** Secure, client-side authenticated dashboard for real-time content management.
- **Countdown Timer:** Live countdown to the event start.

## Tech Stack

- **React 19**
- **TypeScript**
- **Tailwind CSS v3.4**
- **Vite**
- **Framer Motion**

## Getting Started

To run the project locally, ensure you have Node.js installed, then execute:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Navigate to `http://localhost:5173` to view the public site.
